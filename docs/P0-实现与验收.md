# P0 实现与验收记录

日期：2026-10-09。版本：`0.1.3`。

P0 底座代码与安装包已经完成。0.1.3 的 **52 项底座自动测试通过**，语法、manifest 与包内模块引用检查通过。新版浏览器测试运行请求被拒绝，截图与手机布局检查尚未完成；不沿用旧版的 14 项浏览器通过记录。底座测试使用模拟 SillyTavern context，未调用真实模型；尚未执行真实酒馆、真实模型和手机实机验收。因此 18 条 P0 清单记录为 `pending_acceptance`，未勾选为正式通过。

验证结果见 `artifacts/p0-validation.json`，逐项测试输出见 `artifacts/p0-test-results.tap`。报告记录源码 SHA-256、Node 版本和集成环境，避免将一次模拟测试当作实机验收。

0.1.1 新增了魔法棒菜单与弹窗，但当时的模拟宿主提供了酒馆没有的 `off` 接口，且浏览器测试只通过 loopback 地址执行，未覆盖普通 HTTP 的限制。用户报告入口仍不出现，并确认使用局域网 HTTP 后，已分别复现宿主超时、哈希接口缺失和 UUID 接口缺失。

0.1.2 改为兼容酒馆原生 `removeListener`，并在普通 HTTP 下使用 UUID v4 与 SHA-256 兼容实现，保持已有数据格式和摘要值。启动前即挂载入口，失败保留错误面板和重试按钮。新增测试验证安全上下文备份在 HTTP 环境的恢复，以及重试和取消期间不重复绑定事件。

浏览器测试实际确认普通 HTTP 页面的 `isSecureContext === false`、`randomUUID/subtle` 不可用，入口和检查点仍可使用，下载备份校验正确。证据见 `artifacts/p0-ui-validation.json`，普通 HTTP 390px 截图见 `artifacts/p0-http-mobile.png`，错误面板见 `artifacts/p0-startup-error.png`。这些是浏览器引擎内的模拟宿主测试，不等同于用户当前酒馆或安卓/iOS实机验收。

上段浏览器报告与截图对应 0.1.2。0.1.3 重设计记忆档案馆风格，加入记忆联结 SVG、聊天概览、真实日志时间线、档案操作卡片和四页签。概览与时间线从现有 runtime 读取，不增加记忆抽取或存储协议。内置 SVG 与字体回退不依赖外部资源；窄布局以面板宽度切换单列，页签支持方向键、Home 与 End。

新版浏览器脚本包含 17 项检查但尚未执行。`artifacts/ui-redesign-preview.html` 是以实际界面代码生成的示例预览，不是截图或验收证据；不写入聊天或发送模型请求。语法与底座验证仍见 `artifacts/p0-validation.json`。

## 实机验收步骤

执行者需要在酒馆安装本包，打开浏览器控制台并记录酒馆版本、包版本和 API 类型。当前全部未执行。

- [ ] 安装并刷新后，面板出现一次，控制台没有加载错误，`STMemoryCore.getCapabilities()` 返回 apiVersion 1。
- [ ] 左下角魔法棒包含「记忆中枢」，点击直接打开弹窗；关闭和重开后输入保留。顶部扩展设置也能打开同一面板。
- [ ] 用局域网 HTTP 在电脑和手机访问；确认面板显示 0.1.3，打开聊天、创建检查点和导出备份成功。
- [ ] 四个页签可切换，方向键 / Home / End 操作可用；切换、关闭重开保留草稿。检查 320px 与 390px 各页签的溢出与关闭按钮。
- [ ] 启动失败时菜单入口保留，错误面板可读；解决问题后「重试启动」恢复，事件与入口不重复。
- [ ] 连续禁用、启用插件；面板和事件响应不重复，禁用期间任务停止。
- [ ] 同名不同角色、两个群聊和聊天分支的 storeId 不串用。刷新后 storeId 和消息 ID 保留。
- [ ] 编辑、删除、重生成和切换 swipe 后，消息 versionId 与有效事实状态一致；同一操作不会重复写事件。
- [ ] 创建检查点、导出备份，再恢复同聊天的有效备份；修改正文后旧备份被明确拒绝。
- [ ] 用真实主 API 点击测试，收到回复。再用独立 OpenAI 兼容服务测试，密钥不出现在导出的配置、备份或日志中。
- [ ] 测试请求期间切聊天或取消，旧任务不成功发布，后续任务仍可运行。
- [ ] 日志默认不记录提示词与回复正文；主动开启后可记录正文，但凭据仍脱敏。
- [ ] 只读 API 返回值被调用方修改后，内部状态不变；未提取记忆的覆盖缺口能够识别。
- [ ] 验证宿主磁盘/服务器保存失败能通过 Promise reject 反馈。若宿主吞掉 HTTP 错误，需要调整 HostAdapter 并重新执行保存回退测试。

P0 面板未提供事实编辑器，人工事实与锁的产品界面由 P1 接入；其协议已通过自动测试。实机来源回滚可在 P1 记忆提取接入后继续验收。

## 进入 P1 的接口基础

下一阶段新增摘要、故事时间、人物、物品、场景、人工编辑和基础导入；统一通过 runtime.commit 写入，不改变现有 storeId 和 schema v1 的基本约束。抽取结果必须携带当前正文版本依据；缓存和注入材料订阅统一状态变化。

当前不包含旧插件运行入口、提示词素材或旧数据格式直接兼容，也没有自动摘要、向量索引和记忆注入。这些内容继续按清单推进。
