## 使用闭环

1. 在「楼层摘要」启用故事记忆，使用酒馆主 API 或配置独立渠道。摘要、状态提取、压缩可分别路由。
2. 在「记忆工作台 → 分析与审阅」设置起止楼层和批次上限。默认先审阅。批量按楼层顺序分析，后序结果使用前序待审阅状态。
3. 检查待提交摘要和变更明细。可以修订摘要或拒绝结果。确认后序结果会顺序提交所依赖的前序结果，先检查整批。每楼独立保存，停止后已提交结果保留，再扫缺口可继续。
4. 在「人物与状态」维护人物、定向关系、事实/认知、物品、事项、时间线、里程碑和地点树。人工字段可以锁定，修改可撤销；后续修改冲突时拒绝旧撤销。
5. 在「生成材料」检查当前角色范围、分项开关、预览、来源和 token 估计。正文生成前同步来源、读取材料，并将同一组装结果交给宿主。另保留最近一次实际提交内容和版本。
6. 可将互不重叠的摘要节点送去压缩，审阅后使用父节点；撤销使用父节点后恢复子摘要。子项改变会使上层摘要失效。

### 自动任务

自动分析默认关闭，需主动开启。楼数与 token 估计阈值按任一满足触发；每批上限单独生效。隐藏的近期保留窗口与注入的近期排除窗口分别设置。默认自动结果仍先审阅；关闭先审阅才会自动落盘。模型调用可能产生费用。

纯摘要模式不产生人物、物品等状态变更。用户行动默认只作为意图，由后续角色回复结算；可改为用户楼层也提取已发生状态。习惯至少要求两次观察计数；实际依据仍由使用者审阅。`think` 等推理块及自选标签清洗后再提交模型。

自动压缩选择当前有效、不重叠的摘要根节点，可以继续构成更高层节点；不会重复压缩同一有效覆盖范围。审阅模式下可手动压缩已确认节点。

### 隐私与来源

- 摘要、事实、关系、物品及事项有公开、指定知情角色、仅保存三种范围。无法确定的模型摘要默认仅保存。自动识别当前酒馆角色不唯一时，只注入公开材料；群聊可手动指定角色 ID，所有指定角色都必须有知情依据。
- 事实 ID 与角色认知分离，认知保留亲历、听说、怀疑或未知及传播来源。听说、怀疑会在材料中标明。人物内心、情绪和生活档案只对对应单一角色注入。
- 模型状态、摘要和压缩绑定正文版本与前置事件。正文修改、删除、swipe 或排除会使旧结果失效。排除规则回放时参与来源判断，不仅隐藏 UI。
- 标签排除可手动恢复；豁免只针对当前正文版本。下次修改正文后会重新按标签判断。
- 本插件只隐藏已保存有效摘要覆盖的旧楼，标记隐藏归属；恢复不解除用户原先的手动隐藏。正文失去覆盖、被排除或模块关闭后，恢复本插件拥有的隐藏。

## 宿主接入与能力边界

宿主接口核对依据为 [SillyTavern 扩展文档](https://docs.sillytavern.app/for-contributors/writing-extensions/)、[release 分支 context](https://raw.githubusercontent.com/SillyTavern/SillyTavern/release/public/scripts/st-context.js)、[正文生成源码](https://raw.githubusercontent.com/SillyTavern/SillyTavern/release/public/script.js)、[隐藏消息实现](https://raw.githubusercontent.com/SillyTavern/SillyTavern/release/public/scripts/chats.js) 和 [世界书源码](https://raw.githubusercontent.com/SillyTavern/SillyTavern/release/public/scripts/world-info.js)，核对日期 2026-10-10。

- 正文生成优先使用可等待的 `GENERATION_AFTER_COMMANDS`；旧宿主仅有 `GENERATION_STARTED` 时降级，并在能力面板显示差异。注入使用 `setExtensionPrompt` 的聊天内系统位置。实际提交指扩展材料交付给宿主，不承诺等于宿主最终完整请求；宿主还会组装角色卡、世界书及其他扩展材料。
- 主 API 使用宿主 `generateRaw`，采样由宿主控制；主 API 未提供本扩展可用的流式/底层取消保证。独立渠道支持 OpenAI Chat Completions 兼容代理、SSE 和 AbortSignal。
- 世界书扫描是明确标识的基础扫描，不冒充宿主完整递归、向量和概率激活结果。需这些能力的条目跳过并说明原因。没有读取/宏/名称 API 时显示能力差异，保留可核查原文。
- 内置注入宏只有 `{{memory}}`、`{{storyTime}}`、`{{location}}`、`{{language}}`，从已提交快照读取。模块禁用时不执行世界书模板渲染。
- 旧总结导入接受总结字符串或 `{summary,entities,visibility,audienceIds,...}`。未知顶层字段原样备份；支持的实体字段严格校验。没有完整逐楼结构化历史的导入不能标为无损，状态覆盖缺口仍显示；要主动重新分析导入范围，可取消「只扫描缺口」。旧插件完整格式迁移属于 P5。
- P2 向量召回与精确 token 预算、P3 表格/RPG/世界书写回、P4 规划/Agent 执行尚未启用。P1 提供对应分项开关和路由的预留项，不宣称这些模块已运行。
