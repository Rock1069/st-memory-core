# P1 首批实现与验收

此文保留 0.1.4 首批历史记录；当前 0.2.0 的完整 P1 交付与验证见 [P1 实现与验收](P1-实现与验收.md)。

版本：`0.1.4`。P1 已启动，本次交付逐楼摘要的第一段工作流；54 条 P1 项目尚未整体完成。

## 已接入

- `src/core/memory.js` 清洗思维块，找出有正文的用户和角色楼层，计算摘要覆盖与缺口。
- `src/runtime.js` 使用当前消息版本作为证据，通过统一 `runtime.commit` 保存模型或人工摘要。编辑、删除、切换回复页后，旧摘要由事实库重放规则失效；旧模型响应无法在来源变化后提交。
- 自动摘要默认关闭。启用故事记忆模块和自动摘要后，每次正文同步默认最多处理 4 个最新缺口，楼数上限可在界面调整；手动操作每次处理最早 20 个缺口。摘要任务走所选 API 渠道与现有任务队列，能在任务页取消。
- 楼层摘要页面显示覆盖数量、最近 40 个有效楼层、手写/修订入口。人工修订锁定摘要正文；备份导出包含摘要事件。
- 只读快照的 `coverage.summary` 显示有效楼层、已摘数量和缺口 ID；总覆盖仍保持 `complete:false`，避免把逐楼摘要误报为完整记忆提取。历史版本不使用当前正文计算覆盖。

## 验证

执行 `node --test tests/p1-summary.test.js`：4 项通过，覆盖旧配置兼容、思维块清洗、人工摘要来源失效、自动摘要幂等调用和迟到模型响应拦截。`node --check` 对 `src` 全部 JavaScript、入口和测试文件通过。测试使用模拟宿主和模拟模型；真实酒馆与手机布局尚待验收。

## 仍需完成的 P1 工作

摘要压缩树、批量范围与断点、旧楼隐藏、番外排除、故事时间、人物/物品/场景状态、认知隔离、统一提示词组装与实际注入、世界书读取、旧总结迁移等仍按功能覆盖清单逐项开发。当前摘要不会自动发送给正文模型，因此还不能宣称完整长期记忆闭环。
